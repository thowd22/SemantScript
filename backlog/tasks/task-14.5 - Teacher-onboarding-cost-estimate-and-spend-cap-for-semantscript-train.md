## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
A training run through a paid teacher gives the developer no idea what it will cost or how long it will take, and no way to bound it. On 2026-09-25 the Express example's two expressions at 192 cases cost about USD 10 through OpenRouter against an estimate of one dollar, because the teacher prompt is about 8,300 tokens per request, a constrained expression needs about twice as many requests as cases, and an anchor the teacher cannot twin costs three attempts. Setting the teacher up is also manual: init assumes ANTHROPIC_API_KEY and anything else means writing a TOML by hand from the trainer README.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 semantscript train --estimate prints, per expression and in total, the number of teacher requests, the input and output tokens, the cost in USD at the configured backend's price and the expected wall time, without calling the teacher
- [x] #2 --max-cost-usd stops a run before the request that would exceed it, with the cached datasets kept, and every run prints its running cost and request count
- [x] #3 init asks for or accepts a teacher choice (Anthropic, OpenRouter, Ollama, constraints) and writes the TOML; semantscript teacher probe sends one request through the configured backend and reports the model, latency and cost
- [ ] #4 The teacher prompt is measured and reduced (or served through prompt caching) so that a case costs no more than half of the 2026-09-25 figure at equal verification results on the Express example
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Measured baseline (UNDERSTAND, local, free): the Express IR's decideRefund case prompt averages 20,434 characters (system 929; user = indented JSON with the full constraint predicate ASTs, 6,070 chars of constraints, plus a responseSchema copy that output_config already sends); triage averages 3,815. 8,300 tokens / 20,434 chars ~ 2.46 chars per token for this indented JSON. A compact projection (constraints as kind/output/source only, no responseSchema copy, no indent, inputs without index) is ~4,470 chars for decideRefund (-78%) and ~2,390 for triage. OpenRouter GET /api/v1/models (no key) gives anthropic/claude-sonnet-5 prompt 2e-6, completion 1e-5, input_cache_read 2e-7, input_cache_write 2.5e-6 and ':batch' variants at half; 8,300 x 2e-6 + ~80 x 1e-5 = USD 0.0174, matching the recorded 0.017. Half of the 2026-09-25 figure = USD 0.0085 per request.

1. Spend accounting (new trainer/src/semantscript_trainer/teacher_spend.py): TeacherPrice (input/output/cache-read/cache-write USD per million, source pinned|openrouter|config|free); pinned table for Anthropic ids (claude-sonnet-5 2/10, claude-opus-5 5/25, claude-haiku-4-5 1/5; cache read 0.1x, write 1.25x; batch 0.5x); resolve_price(config): constraints and ollama -> zero; anthropic with an openrouter.ai base_url -> OpenRouter /api/v1/models (cached in <cache-dir>/teacher-prices.json with fetch date, pinned fallback offline), else the pinned table; [teacher.pricing] (input_usd_per_million, output_usd_per_million, cache_read_usd_per_million, cache_write_usd_per_million, seconds_per_request) overrides; unknown model with no override -> typed TeacherConfigurationError naming [teacher.pricing]. Pricing is excluded from public_projection so it never changes dataset digests. SpendMeter: requests, input/output/cache tokens, USD, elapsed; charge(usage) from Anthropic usage (input_tokens, output_tokens, cache_creation_input_tokens, cache_read_input_tokens) and Ollama usage (prompt/completion tokens, zero cost); reserve(estimated_usd) raises TeacherBudgetExceeded (new TeacherError subclass) before a request when spent + estimate > max_cost_usd; progress line every 25 requests and per expression.
2. Wire the meter into AnthropicTeacher (_generate_direct, _request_adversarial: reserve before each create, charge after; submit_batch: reserve the whole batch at the batch price before submitting, charge on collect) and OllamaTeacher (count, latency, zero cost) through a provider option meter=; ConstraintsTeacher passes it to its fallback; no meter = current behavior. Request estimate for reserve() = the request's own prompt characters / chars-per-token ratio + max(observed mean output, pinned 110).
3. Response journal so a stopped run loses no paid work: <cache-dir>/teacher-responses/<descriptor digest>/<sha256(request params)>-<occurrence n>.json written after each successful direct request and replayed (charged USD 0) on rerun; occurrence counting keeps retries of an identical prompt distinct; complete datasets stay in the existing dataset/adversarial caches. Datasets finished before a stop are never deleted.
4. Estimate (new trainer/src/semantscript_trainer/teacher_estimate.py, no teacher call, no torch/tokenizer load): per function, skip build-cache reused functions and datasets whose cache file exists (SyntheticDatasetGenerator.cache_path / AdversarialDatasetGenerator.cache_path when the base is cached); requests = synthetic (cases - gold) + one per constraint (boundary) + ratio_count(synthetic, counterfactual_ratio) (twins), expected with a documented retry factor calibrated on the Express run (~600 requests for the planned ~480) and a maximum (4 replacement rounds, 3 attempts per boundary/twin, one skip per wanted pair); input tokens = characters of the exact prompts built by build_case_messages/build_boundary_messages/build_counterfactual_messages (anchor = a gold example) plus the wire schema, divided by a documented chars-per-token ratio (calibrated from the usage of the probe requests in step 9; stated in output and docs); output tokens = serialized case size / ratio (+ reason for twins); USD at the resolved price (cache reads when caching applies, batch price for mode batch/auto above batch_threshold); wall time = requests x seconds_per_request (config override, else the mean latency the last metered run recorded in <cache-dir>/teacher-stats.json for this descriptor, else pinned: Sonnet direct 4 s, Ollama 1 s documented as a pinned figure, constraints 0; batch printed as up to 24 h). Output kind semantscript.train-estimate v1 (per function and total: requests expected/max, input/output tokens, USD, seconds; price source; ratio).
5. Trainer CLI (cli.py): train --estimate (writes the estimate JSON to stdout, exits 0, never creates the teacher client), --max-cost-usd <x> (positive finite; meter cap), teacher probe subcommand (--teacher, --json: one request via doctor.probe_teacher, reports model, latency, tokens, USD at the resolved price; constraints -> 'no request, USD 0'; mixed -> probes the fallback). Train report gains a teacher spend object {requests, replayed, inputTokens, outputTokens, cacheReadTokens, costUsd, maxCostUsd} (REPORT_VERSION stays 1: additive, Node parser tolerant) and the stderr log prints running cost/request lines; TeacherBudgetExceeded is caught with 'error: spend cap USD x reached after n requests (USD y spent); completed datasets and n journaled responses are cached; rerun with a higher --max-cost-usd to resume' and exit 1.
6. Prompt reduction (AC4): teacher_prompt.build_case_messages and adversarial_prompt send a compact contract: constraints as {kind, output, source} (no predicate AST; the local checks still use it), inputs as {name, type, tsType}, no responseSchema copy (both Anthropic output_config and Ollama response_format carry the schema), compact JSON; the stable contract goes first as a system block with cache_control ephemeral (prompt caching through Anthropic and OpenRouter's Anthropic route; below the model's minimum cacheable length it is simply not cached), the per-case brief in the user message.
