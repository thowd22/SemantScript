## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-5.11 requires two disjoint held-out sets (release verification and final evaluation) whose inputs were not generated by any teacher and whose labels carry an attestation. The user decided on 2026-09-23 that human authorship is not the better path and asked for full automation with Claude Fable 5.1 as the judge. Provenance must stay honest: the dataset and release-verification contracts currently admit only human-authored or other-held-out origins with a humanAttestation block, so a new independent-judge origin with its own attestation (judge identity, committed rubric digest, declaration that no training teacher produced inputs or labels) is needed across the TypeScript contracts, JSON schemas, Python pipeline, and tests. Inputs come from UCI Online Retail II (real UK retailer transactions 2009-2011, CC BY 4.0), de-identified and mapped onto the compiled refund schema with a documented derivation; a small documented subset has order.status set to fraudulent by the judge so the never-approve constraint is exercised. Labels are adjudicated case by case by Claude Fable 5.1 in-session under a committed rubric with recorded rationales. The two sets must be mutually disjoint and disjoint from the frozen Sonnet 5 pilot corpus.
