# Refund benchmark: results and go/no-go (2026-09-24)

This file records the first complete run of the Phase 1 exit benchmark: the
canonical refund-decision function compiled from `program/refund-with-confidence.sem.ts`
(function `nf_65e347f7…`, semantic digest `f7efe891…`, task spec `ffc5c594…`),
trained through the release pipeline and measured against the baselines on the
frozen final set. Every number below is derived from committed, digest-bound
records under `data/`; the machine-checked result is `data/results-v2-2026-09-23/result.json`.

## Decision

**Accuracy: met.** SemantScript answers 159 of 160 judge-attested final cases
correctly (0.994) against 0.538 for the Qwen 2.5 7B comparator, 0.519 for the
1.5B model and 0.225 for Laya. Its 15-bin calibration error is 0.011; the
generative baselines sit above 0.42 because they report near-certain
distributions on wrong answers.

**Latency: not met as deployed.** The exported artifact runs on CPU through
`onnxruntime-node` with a median of 38.4 ms per call (p95 50.5 ms), against the
exit bar of p50 strictly below 10 ms. A steady-state re-measurement outside the
harness gives the same figure (p50 36.6 ms over 300 calls). The cost is
arithmetic, not configuration: ModernBERT-base is 22 layers and about 149 M
parameters in fp32, and the canonical input serialization spends roughly 100 to
115 tokens on five fields, so one call is on the order of 30 GFLOP on a 12-core
CPU. The 4x gap will not close with session settings; it needs a smaller or
quantized encoder and a more compact canonical encoding, which is Phase 2 work.

**Mechanical status: `incomplete`.** The result file's exit decision is
`incomplete` because the required structured-output API baseline never ran (no
`ANTHROPIC_API_KEY` on the machine). Had it run, the mechanical decision would be
`no-go` on the latency criterion and `go` on the accuracy criterion.

**Written decision: no-go for Phase 1 exit on latency; the accuracy criterion is
met with a wide margin.** The end-to-end primitive works: compile, generate,
train, verify against attested real inputs, export, and serve from Node with
calibrated confidence. What blocks exit is the deployed cost of the encoder, not
the approach.

## What was measured

**Task.** Three-way refund decision (`approve`, `deny`, `review`) from a customer
record (`tier`, `priorRefunds`) and an order record (`total`, `ageDays`, `status`).
The policy is stated completely in the sema source and every rule is also an
`always`/`never` constraint (decision-6): orders older than 90 days are denied;
fraudulent orders are never approved and are reviewed when not stale; paid orders
outside the tier window (60 days enterprise, 30 days standard) are denied; paid
orders inside the window are reviewed when the customer has more than two prior
refunds and approved otherwise.

**Held-out sets (decision-5, TASK-5.16).** Inputs are real, de-identified
cancellation requests derived from UCI Online Retail II (CC BY 4.0) by the
committed extraction script; a hash-selected 15 percent carry the `fraudulent`
status. Labels were adjudicated case by case by an independent model judge
(`claude-fable-5-1`, rubric digest `e135ca26…`, evidence digest `074f240e…`)
and are recorded under the `independent-judge` origin with a judge attestation.
No record claims human authorship. The release-verification set (80 cases,
payload `d21ab8cc…`) gates the artifact; the final benchmark set (160 cases,
payload `5d71fc08…`) is never seen by training, calibration or verification,
which the training-input ledger proves by digest. Age strata: 0-30, 31-60,
61-90 and over 90 days.

**Training corpus (decision-7, `data/pooled-v4-2026-09-24`).** 9,035 synthetic
rows: 7,535 real-distribution inputs from the UCI candidate pool (held-out
inputs excluded by digest, 749 excluded at sampling time) labeled with the
unique output the compiled constraints admit, 1,500 `claude-opus-5-5` teacher
cases replayed from the Opus corpus, and status-flipped twins of every stale
order; plus 374 adversarial cases (12 constraint-boundary, 362 counterfactual
in 181 pairs) generated by `claude-opus-5-5` through the Claude Code CLI teacher.
Zero conflicting inputs.

**Student.** ModernBERT-base (revision `8949b909…`) with a classification head,
fine-tuned on AMD ROCm for 8 epochs (batch 16, learning rate 3e-5, linear
schedule with 5 percent warmup, best-epoch selection on a 10 percent calibration
split, seed 2), temperature-calibrated, then verified against the 80
attested release cases with a 1 percent constraint-violation tolerance
(decision-8). The exported artifact runs on CPU in the Node runtime through
`onnxruntime-node`; the benchmark measures that deployed path, not the GPU.

**Baselines.** Qwen 2.5 1.5B and 7B instruct (Q4_K_M) through Ollama 0.34.3 on
the same GPU, and Laya typed-decisions (code `d120d4ba…`, checkpoint
`dd079950…`) on ROCm, all prompted with the same six-rule policy and the same
strict decision-plus-distribution output. The traditional structured-output API
baseline (`claude-sonnet-5`) did not run because no `ANTHROPIC_API_KEY` was
available on the benchmark machine; the mechanical exit decision therefore
reads `incomplete` by construction, and the go/no-go below is the written
decision the task requires.

**Protocol.** One shared environment record (Linux 6.18 WSL2, Ryzen 9 9900X,
RX 9070 XT, 16 GiB), concurrency 1, ten warmup iterations over eight synthetic
inputs disjoint from the evaluation set, client-only memory scope, nearest-rank
latency percentiles, 15-bin top-1 expected calibration error.

The single SemantScript miss is a standard-tier customer with one prior refund
and a fraudulent order at 62 days (total 105.08): expected `review`, predicted
`deny` with probability 0.87. It sits where the fraud rule overrides the
outside-window rule; the training corpus is thin exactly there (the release
attempt that failed before the passing seed missed a case in the same region,
an enterprise fraudulent order at 68 days), so a status-twin partition for
orders inside 90 days but outside the tier window is the obvious next
augmentation.

Release evidence for the committed artifact (`data/release-2026-09-23/`): seed 2,
best epoch 6 of 8, calibration split 941 rows, temperature 1.97, calibration
accuracy 0.990, ECE 0.004, pair consistency 1.0, zero attested release misses,
14 constraint violations across 9,489 verification records (0.15 percent,
under the 1 percent tolerance). The first attempt on this corpus (seed 1)
passed verification but crashed on a lifecycle defect fixed in commit
`8d8d407`; the rerun of seed 1 missed one release case; seed 2 passed. The
571 MB artifact bundle itself is not in git; its manifest digest is bound by
the pipeline manifest and the prediction record.

## Interpretation and caveats

- **What accuracy means here.** Labels are an independent model's adjudication
  of an explicit numeric policy on real inputs, and the student was trained on
  real-distribution inputs labeled by the compiled constraints. The number is
  agreement with a documented policy interpretation, not with human judgment,
  and it measures how well a compiled encoder learns an explicit policy from
  text on the traffic it is deployed on.
- **Generative baselines under the same explicit policy.** Both Qwen models
  received the full six rules and still fail whole rule regions (the 1.5B model
  never denies stale or outside-window orders; the 7B model never reviews fraud
  and rarely denies outside-window orders). Laya answers `review` for every
  case. Their numbers are ceilings for zero-shot prompting at that size, not for
  fine-tuned models of that size.
- **Release-gate variance.** Training on ROCm is not bit-reproducible; identical
  configurations differed by one or two attested release cases between runs,
  so the release loop ran seeds until one passed the zero-miss gate. The passing
  artifact is the one committed; failed attempts are recorded in the task notes.
- **Threshold learning is token-level.** A probe of an earlier corpus showed a
  model that denied fraudulent stale orders at 91, 95, 105, 120 and 200 days
  but answered `review` at exactly 99 days, a value absent from that corpus.
  Constraints remain build contracts: hard rules that must hold for every
  production input stay deterministic TypeScript guards, as the spec requires.
- **Missing baseline.** The structured-output API row is absent; the decision
  compares against the local 7B model as the exit criterion specifies.

## Reproduction

```sh
PYTHONNOUSERSITE=1 HSA_ENABLE_DXG_DETECTION=1 \
PYTHONPATH=.:trainer/src:model/src:.python-packages \
python3 -m benchmarks.refund.program.run_release_pipeline \
  --corpus-manifest benchmarks/refund/data/pooled-v4-2026-09-24/manifest.json \
  --heldout-dir benchmarks/refund/data/heldout-uci-2026-09-23 \
  --output-dir benchmarks/refund/data/release-2026-09-23 \
  --epochs 8 --batch-size 16 --learning-rate 3e-5 --evaluation-ratio 0.1 \
  --max-sequence-length 128 --device cuda --seed 2 --select-best-epoch \
  --learning-rate-schedule linear --warmup-ratio 0.05 \
  --maximum-constraint-violation-rate 0.01

node benchmarks/refund/program/run-benchmark.mjs run \
  --dataset benchmarks/refund/data/heldout-uci-2026-09-23/final-benchmark-dataset.json \
  --output-dir benchmarks/refund/data/results-v2-2026-09-23 \
  --warmup-source benchmarks/refund/data/sonnet-pilot-2026-09-23/synthetic/datasets/v1/d3/d35bc8b85dd0fadadc74c46e176d666cd325faf18bc0e0e0231076ad07287c05.json \
  --systems ollama-1b,ollama-7b,laya,semantscript \
  --pipeline-manifest benchmarks/refund/data/release-2026-09-23/pipeline-manifest.json \
  --laya-source <pinned laya checkout> --laya-checkpoint <pinned snapshot> \
  --accelerator "AMD Radeon RX 9070 XT (gfx1201, ROCm via WSL2 DXG)"

node benchmarks/refund/program/run-benchmark.mjs assemble \
  --dataset benchmarks/refund/data/heldout-uci-2026-09-23/final-benchmark-dataset.json \
  --ledger benchmarks/refund/data/release-2026-09-23/training-input-ledger.json \
  --output-dir benchmarks/refund/data/results-v2-2026-09-23
```
